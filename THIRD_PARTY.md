# Credits and preserved originals

Stick Box is an independent tribute to Stickpage and its creators, not an
official Stickpage website. Original works remain attributed in `catalog.json`
and on each watch page. Preservation does not transfer ownership of those works.
Original pages/download links, local SHA-256 hashes and unexecuted source-page
snapshots are retained under `archive/`; see its README for unavailable sources.

The bundled Ruffle player is upstream `@ruffle-rs/ruffle` version 0.6.0,
copied byte-for-byte from Aero's pinned local runtime. It is available under
MIT or Apache-2.0; both upstream license files are included in `ruffle/`.
Its original package metadata and README are retained there.
